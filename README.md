# 🏢 Site Institucional e Meio de Contato - ASAS

Este repositório contém o código-fonte de um site institucional desenvolvido para fins profissionais e de portfólio, atuando como canal de apresentação e meio de contato direto para a empresa.

🔗 **Acesse o site ao vivo:** [https://gabrieldoalmo.github.io/Site-para-empresa/](https://gabrieldoalmo.github.io/Site-para-empresa/)

---

## 🚀 Sobre o Projeto
O projeto foi desenvolvido com foco em performance, experiência do usuário (UX) e design limpo. Trata-se de uma aplicação web responsiva voltada para o setor de construção e serviços, permitindo que clientes conheçam o portfólio de obras, serviços prestados, informações institucionais e entrem em contato de forma prática.

## 🛠️ Tecnologias Utilizadas
* **HTML5 / CSS3:** Estruturação semântica e estilização customizada com design moderno.
* **JavaScript (ES6+):** Interatividade da interface, manipulação do DOM e lógica de navegação.
* **Responsividade:** Layout adaptado e otimizado (Mobile-First) para visualização fluida em smartphones, tablets e computadores.

## ✨ Funcionalidades
* **Páginas Institucionais:** Home, Quem Somos, Serviços, Portfólio e Contato estruturadas de forma modular.
* **Visualização de Portfólio:** Seção dedicada a cases e imagens de projetos realizados.
* **Central de Atendimento / Contato:** Canais e formulários integrados para facilitar a conversão de clientes.
